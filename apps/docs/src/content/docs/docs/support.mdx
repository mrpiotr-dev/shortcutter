---
title: Feedback and support
description: How to report a bug, ask a question, suggest a feature or a docs fix, and report a security issue.
---

Every report is read. Bugs are usually triaged within a few days.

## Report a bug

Open a [bug report](https://github.com/mrpiotr-dev/shortcutter/issues/new?template=bug_report.yml) on GitHub. The form asks for what makes keyboard bugs reproducible:

- the shortcut you registered and the keys you pressed;
- the package and version, such as `shortcutter 0.4.0` or `@shortcutter/react 0.4.0`;
- your browser and operating system;
- your **keyboard layout** (US QWERTY, German QWERTZ, French AZERTY…), because shortcuts follow physical keys;
- a minimal code sample, or a link to a reproduction on StackBlitz, CodeSandbox or a repository.

Please search the [existing issues](https://github.com/mrpiotr-dev/shortcutter/issues) first; adding details to an open one helps too.

## Ask a question or share feedback

Use [GitHub Discussions](https://github.com/mrpiotr-dev/shortcutter/discussions) for questions ("how do I…?"), ideas you want to talk through, or general feedback about the library.

## Suggest a feature

Open a [feature request](https://github.com/mrpiotr-dev/shortcutter/issues/new?template=feature_request.yml). Describe the use case first: what you are building and where the current API gets in the way.

## Improve this documentation

Found a mistake, an unclear explanation or a broken example? Every page has a **Report a problem with this page** link at the bottom. It opens a [docs issue](https://github.com/mrpiotr-dev/shortcutter/issues/new?template=docs.yml) with the page already filled in.

## Report a security issue

Please **do not** open a public issue. Report it privately through [GitHub private vulnerability reporting](https://github.com/mrpiotr-dev/shortcutter/security/advisories/new), or by email to [contact@mrpiotr.dev](mailto:contact@mrpiotr.dev). The [security policy](https://github.com/mrpiotr-dev/shortcutter/blob/main/SECURITY.md) explains what happens next.
